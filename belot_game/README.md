# Белот онлайн

Български белот за 4 играчи в браузъра. Празните места могат да се заемат от ботове.

## Пускане

```
pip install -r requirements.txt
python run.py
```

Отвори http://localhost:5000, създай маса и прати линка от лобито.

- **Същата мрежа (Wi-Fi):** линкът в лобито е с локалния ти IP, например `http://192.168.x.x:5000/r/КОД`.
  При първото пускане Windows ще попита за защитната стена – разреши достъпа.
- **През интернет:** инсталирай `cloudflared` (`winget install --id Cloudflare.cloudflared`) и пусни
  `python run.py --tunnel`. В конзолата ще се появи публичен линк `https://….trycloudflare.com`.

## Структура

- `belot/engine.py` – правилата: обявяване, контра/реконтра, задължения при игра, анонси, белот, точкуване, „вътре“, висящи, капо.
- `belot/bots.py` – прости ботове.
- `belot_app.py` – Flask сървър със стаи. Браузърите питат за състоянието на всеки ~0.35 сек (polling),
  затова работи и на PythonAnywhere (без WebSockets).
- `static/`, `templates/` – интерфейсът.

## Опростявания в тази версия

- Анонсите се обявяват автоматично при първата карта на играча.
- Всички карета се зачитат; от поредиците се зачитат само тези на отбора с най-високата поредица (при равенство – никой).
- Картите от каре не участват в поредици.
- Стаите се пазят в паметта – при рестарт на сървъра изчезват.
