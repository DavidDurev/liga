# Селска Футболна Лига

Сайт за седмични прогнози на 5 футболни мача в приятелска група, с автоматично класиране.

## Точкуване

За всеки мач се въвеждат коефициентите **1 / X / 2** от betano.bg. При приключване на мача:

| Прогноза | Точки |
|---|---|
| Познат изход (1 / X / 2), но не точен резултат | **1 × коефициент** на познатия изход |
| Точен резултат | **3 × коефициент** на познатия изход |
| Непознат изход | 0 точки |

Пример: коефициент за "1" е 2.10, играч прогнозира 2:1, реалният резултат е 2:1 → 3 × 2.10 = **6.3 точки**.
Ако беше познал само изхода (напр. 1:0), щеше да получи 1 × 2.10 = **2.1 точки**.

## Инсталация

Изисква се Python 3.9+.

```bash
cd selska-liga
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Отвори `http://127.0.0.1:5000` в браузъра.

Базата данни (`liga.db`, SQLite) се създава автоматично при първо стартиране — не се налага никаква ръчна настройка.

## Първи стъпки

1. **Регистрирай се** — първият регистриран потребител автоматично става **администратор**.
2. Като администратор, отиди в **Админ → Създай нова седмица**.
3. Добави до 5 мача с отбори, начален час и коефициенти (1 / X / 2) от betano.bg. Всеки мач приема прогнози до **5 минути преди своя начален час** — крайният срок е индивидуален за всеки мач, не за цялата седмица.
4. Покани останалите играчи да се регистрират и да въведат прогнозите си преди съответните срокове.
5. След като мачовете приключат, въведи реалните резултати в **Админ → Седмица N** — точките се изчисляват автоматично.
6. Класирането (общо и по седмици) е видимо в раздел **Класиране**.
7. От **Админ → Потребители** можеш да изтриваш потребители (заедно с прогнозите им). Не може да изтриеш себе си, нито последния останал администратор.

Часовете (начален час на мач) се третират като **българско време** (Europe/Sofia) — важи независимо къде физически работи сървърът.

## Достъп за приятели през интернет (безплатно, с фиксирано име)

Сайтът вече слуша на всички мрежови интерфейси (`0.0.0.0`), не само локално — готов е да бъде достъпен отвън.

1. **DuckDNS** (duckdns.org) — регистрирай се безплатно (през Google/GitHub), създай поддомейн, напр. `selska-liga.duckdns.org`, и копирай своя token.
2. Инсталирай малък ъпдейтър, който да съобщава на DuckDNS текущия ти публичен IP на всеки 5 мин. (DuckDNS дава готов скрипт/инструкции за Windows и Linux от техния сайт след като си влязъл в акаунта).
3. На рутера си отвори панела за администриране и намери **Port Forwarding** — пренасочи външен порт 5000 към локалния IP на лаптопа ти (виж го с `ipconfig` на Windows) и порт 5000.
4. Смени `SECRET_KEY` в `app.py` (или го задай като environment variable `SECRET_KEY`) с произволна дълга случайна стойност — важно, защото по подразбиране е публично видима в кода.
5. Пусни `python app.py` и прати на приятелите линк: `http://selska-liga.duckdns.org:5000`.

Работи, докато лаптопът е включен, свързан към интернет и приложението работи. Ако интернет доставчикът ти ползва CGNAT (нямаш истински публичен IP — среща се основно при мобилни/4G връзки), port forwarding няма да проработи; в такъв случай Cloudflare Tunnel вариантът по-горе е по-сигурен избор.

## Бележки

- Коефициентите се въвеждат **ръчно от администратора** — не се теглят автоматично от betano.bg.
- Всеки играч може да редактира прогнозите си многократно до крайния срок.
- Ако искаш да пуснеш сайта постоянно (не само локално), ще трябва хостинг (напр. PythonAnywhere, Render, VPS) и смяна на `SECRET_KEY` в `app.py` с истинска тайна стойност (чрез environment variable `SECRET_KEY`).
