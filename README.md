# Селска Футболна Лига

Сайт за седмични прогнози на 5 футболни мача в приятелска група, с автоматично класиране.

## Точкуване

За всеки мач се въвеждат коефициентите **1 / X / 2** от betano.bg. При приключване на мача:

| Прогноза | Точки |
|---|---|
| Познат изход (1 / X / 2), но не точен резултат | **1 × коефициент** на познатия изход |
| Точен резултат | **3 × коефициент** на познатия изход |
| Непознат изход | 0 точки |

Пример: коефициент за "1" е 2.10, играч прогнозира 2:1, реалният резултат е 2:1 → 3 × 2.10 = **6.3 точки**.
Ако беше познал само изхода (напр. 1:0), щеше да получи 1 × 2.10 = **2.1 точки**.

## Инсталация

Изисква се Python 3.9+.

```bash
cd selska-liga
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Отвори `http://127.0.0.1:5000` в браузъра.

Базата данни (`liga.db`, SQLite) се създава автоматично при първо стартиране — не се налага никаква ръчна настройка.

## Първи стъпки

1. **Регистрирай се** — първият регистриран потребител автоматично става **администратор**.
2. Като администратор, отиди в **Админ → Нова седмица**, задай краен срок за прогнози.
3. Добави до 5 мача с отбори и коефициенти (1 / X / 2) от betano.bg.
4. Покани останалите играчи да се регистрират и да въведат прогнозите си преди срока.
5. След като мачовете приключат, въведи реалните резултати в **Админ → Седмица N** — точките се изчисляват автоматично.
6. Класирането (общо и по седмици) е видимо в раздел **Класиране**.

## Бележки

- Коефициентите се въвеждат **ръчно от администратора** — не се теглят автоматично от betano.bg.
- Всеки играч може да редактира прогнозите си многократно до крайния срок.
- Ако искаш да пуснеш сайта постоянно (не само локално), ще трябва хостинг (напр. PythonAnywhere, Render, VPS) и смяна на `SECRET_KEY` в `app.py` с истинска тайна стойност (чрез environment variable `SECRET_KEY`).
